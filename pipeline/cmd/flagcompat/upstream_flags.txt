# Curated upstream CLI-flag inventory for the flag-compatibility metric.
#
# Format (whitespace-separated):
#   <tool>[/<subcommand>]  flag flag flag ...
# where each flag token is the BARE name (no leading dashes). Single-character
# tokens are upstream short flags; multi-character tokens are upstream long
# flags. Both forms count as one slot in the denominator.
#
# Provenance (how each upstream flag set was derived — all from primary
# sources under reference_code/, which are read-only upstream submodules):
#   seqtk      getopt() optstrings in reference_code/seqtk/seqtk.c (per stk_* fn)
#   sickle     getopt_long optstring + longopts in reference_code/sickle/src/*.c
#   skewer     argv switch cases + usage "-x, --long" pairs in
#              reference_code/skewer/src/parameter.cpp
#   fastp      cmd.add("long", 'short', ...) calls in reference_code/fastp/src/main.cpp
#   prinseq    GetOptions(...) list in reference_code/prinseq/prinseq-lite.pl
#   vcftools   "--opt" tokens in reference_code/vcftools/src/cpp/parameters.cpp
#   mosdepth   documented docopt usage (mosdepth v0.3.x); cross-checked against
#              tools/mosdepth/README.md which marks port-only aliases
#   bgzip/tabix/htsfile  getopt_long optstring + longopts in reference_code/htslib/*.c
#   samtools   getopt_long optstrings + longopts arrays in reference_code/samtools/*.c
#              (+ SAM_OPT_GLOBAL_OPTIONS from sam_opts.h where the macro is used)
#   bcftools   getopt_long optstrings + longopts arrays in reference_code/bcftools/*.c
#   bed*       documented per-subcommand help flags (PARAMETER_CHECK / usage text)
#              in reference_code/bedtools/src/<sub>/*.cpp. For Context-framework
#              subcommands the DOCUMENTED per-tool flag set is used (not the full
#              inherited ContextBase parser union), matching the tool's own help.
#
# This measures flag-surface acceptance (does our port accept the same flag
# spelling), NOT semantic equivalence — see flag_compat.md.
